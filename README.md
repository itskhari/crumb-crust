This is a java based application that simulates a deli shop POS system.
Features Include:
- Custom Sandwich Builder
- Random Order Generator
- Screen Navigation
- Receipt Writer
- UI Formatting

 The Random Sandwich Generator makes a realistic sandwich by:
 - Picking 1 Meat
 - Picking 1 Cheese
 - 0-4 veggies
 - 0-2 sauces
 - Optional Drink
 - Optinal Chips
this makes selecting a order a breeze when you may be in a rush or just wants something new.
